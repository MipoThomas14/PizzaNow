# 🍕 PizzaNow — Pizza Order and Delivery System

## Overview
**PizzaNow** is a Java-based desktop application designed for a small, family-owned pizza shop offering **pickup** and **delivery** orders only (no dine-in).  
The system enables staff to manage customer records, process new and returning customer orders, calculate totals, and issue digital receipts — all through a simple, intuitive GUI.

## 🎯 Project Description
PizzaNow is built to handle every core function of a  small-scale pizza business:

- Maintain a customer database keyed by phone number.  
- Take new and repeat orders quickly and efficiently.  
- Track payment types (cash, check, or credit).  
- Provide full menu access with customizable pizzas and beverages.  
- Generate itemized receipts and order confirmations.
